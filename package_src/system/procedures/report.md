# Procedure: Report

Use this procedure to write the session report.

1. Copy `templates/session-report.md`.
2. Write the pitch card at the top.
3. Write the summary table. Use one row for each Shark: decision, probability, usual offer rate, signal, and offer.
4. Write each verdict in full, in the order that you judged them.
5. Write the "Where they agree" section. List the points that two or more Sharks made.
6. Write the "Where they split" section. List the points where the Sharks did not agree.
7. Write the "Next steps" section. List the three objections that occur most often, and one action for each.
8. Write the notice at the end. Copy it exactly from the template.

Do not write one combined decision. Do not average the probabilities.
