# Procedure: Intake

Use this procedure to collect the pitch facts and write the pitch card.

## 1. Read what the user gave

1. Read the message of the user.
2. Write down each fact that the user gave.

## 2. Ask for the missing facts

The Sharks judge on numbers. These facts are necessary:

| Fact | Example |
|---|---|
| What the business sells, and to whom | "A refill subscription for pet shampoo, sold to dog owners" |
| The ask in dollars | 150000 |
| The equity offered, in percent | 10 |
| Sales in the last 12 months, in dollars | 240000, or "pre-revenue" |

These facts are useful:

| Fact | Example |
|---|---|
| Gross margin, in percent | 55 |
| Customers or other proof of demand | "1,800 subscribers, 70% stay after 3 months" |
| Founder background | "10 years as a dog groomer" |
| Use of the money | "Inventory for a national retail order" |
| Industry | "Pet Products" |

1. Find the necessary facts that are missing.
2. Ask the user for all missing facts in one message.
3. Do not ask more than one time.
4. If the user does not give a fact, write "Not disclosed" for that fact.

CAUTION: Do not invent a number. A Shark treats a missing number as a weakness. An invented number gives a false result.

## 3. Write the pitch card

1. Copy `templates/pitch-card.md`.
2. Fill in each field.
3. Calculate the implied valuation: ask divided by (equity percent / 100).
4. Write the industry. Use one name from the industry list in `precedents/INDUSTRIES.md`. If no name fits, use "Uncertain/Other".
