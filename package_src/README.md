# The Tank

The Tank is a set of six investor models. Each model uses the public record of one original Shark Tank investor. Each model judges your business pitch independently. You get six decisions, offer terms, objections, and the hard questions to prepare for.

The Tank is only folders and markdown files. It works with each AI that can read files: Claude, ChatGPT, Codex, Gemini, Hermes, and others.

## Contents

| Item | Description |
|---|---|

| `upload-pack/` | The same system in 7 files, for chat assistants with a project feature |
| `workspace/` | The folder where your sessions are saved |
| `LICENSES.md` | The data sources and their licenses |

## Install

1. Unzip the file.
2. Open your AI.
3. Give `INSTALLER.md` to your AI. Attach the file, or paste its text.
4. Do the steps that the AI gives you.

The AI tells you when the install is complete. The AI also does a self-test and tells you the result.

## Use

1. Open a session with your AI in the installed folder or project.
2. Say "New pitch".
3. Describe the business. Include the ask, the equity, and your sales.
4. Answer the questions of the AI.
5. Read the report.

For more commands and for troubleshooting, read `OPERATIONS-MANUAL.md`.

## The six models

| Model | Lens |
|---|---|
| Cuban | Sales and the founder's grit |
| O'Leary | Cash flow and royalty structures |
| Corcoran | The founder as a person |
| Greiner | Retail and TV-shopping fit |
| Herjavec | Scale and the founder's ability to sell |
| John | The founder's influence and fit with his portfolio |

Each model uses beliefs from public interviews and writing. Each quote in a model is verified word for word against its source. Each model also uses the on-air deal record of that investor.
